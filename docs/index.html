Install in 5 minutes

No technical knowledge needed.

  1. Download Distinct.zip, right-click it → Extract All.
  2. Open the folder and double-click Install Distinct.cmd. If Windows shows "Windows protected your PC", click More info → Run anyway. It installs what's needed and adds a desktop icon.
  3. A page opens. Choose a master password. It protects everything and can't be recovered, so keep it safe.
  4. Follow the setup guide: click Sign in with Claude (or pick free models), pair Telegram with a 6-digit code, and turn on phone access.
  5. Text your assistant: "Find me a padel court for Saturday morning."

Developers: git clone https://github.com/ClaudioAk/Distinct.git → npm install → npm start. Node 24+.
